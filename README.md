# 🤝 solo-to-squard

A minimal, intent-driven platform to help builders, designers, and dreamers **find the right collaborators** based on vibe, goals, and skills — not just resumes.

---

## 🔧 Tech Stack (suggested)

- Frontend: `Next.js + Tailwind CSS`
- Backend: `Next.js server actions / API routes`
- DB: Prisma + Pg

---

## 🚀 Features

### 🔑 Core MVP

#### 1. Profile Builder

Capture what matters:

- **Name & Role** (Dev, Designer, PM, Biz)
- **Skill Tags** (React, UX, AI, etc.)
- **Goals** ("Find a co-founder", "Jam on weekends")
- **Time Commitment** (e.g. 5 hrs/week)
- **Vibe Preference** (chill, serious, fast-paced)

> 🔍 Focus is on **intent**, not resume.

---

#### 2. Interest-Based Matching

Match users who:

- Have **complementary skills**
- Share **goals or availability**

> _UX Example:_  
> “You + Jane (UX Designer) both wanna build AI tools on weekends. Want to connect?”

---

#### 3. Connection Requests

Mini LinkedIn-style:

- Send quick message → Accept / Decline
- Start simple conversation (Inbox)

---

### 🌟 Bonus: “You Might Click” Feed

A weekly feed of 3–5 curated profiles:

- _"Looks for beta testers"_,
- _"Weekend hacker"_,
- _"Wants to collab on AI tools"_

---

## 🧠 Why This Works

- Curated + lightweight
- Clear possibility: "I could meet _my person_ here"
- Instant dopamine from suggested matches
